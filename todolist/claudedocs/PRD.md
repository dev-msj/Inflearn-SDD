# PRD: todolist

## 1. 개요

### 프로젝트 목적
혼자 사용하는 사용자가 자신의 할 일을 한 화면에서 등록하고, 완료 여부를 표시하며, 마감일 기준으로 정렬해 확인할 수 있는 개인용 할 일 목록을 제공한다.

### 타겟 사용자
- **개인 사용자 (1인 사용)**: 별도의 계정 생성이나 로그인 없이, 자신의 기기에서 혼자 할 일을 관리하는 사용자
- 다른 사람과 목록을 공유하거나 협업할 필요가 없음
- 하루에 관리하는 할 일이 대략 5~50건 수준인 사용자

### 핵심 가치 제안
- **진입 장벽 0**: 가입/로그인 절차 없이 화면에 접속한 즉시 할 일을 등록할 수 있다.
- **기록 유지**: 화면을 새로고침하거나 브라우저를 닫았다가 다시 열어도 등록한 할 일이 그대로 남아 있다.
- **마감 중심 정리**: 마감일이 임박한 순서대로 할 일을 확인해, 무엇을 먼저 해야 하는지 한눈에 판단할 수 있다.

## 2. 기능 요구사항

### 기능 1: 할 일 등록 및 삭제

**사용자 스토리**
> 개인 사용자로서, 떠오른 할 일을 목록에 등록하고 더 이상 필요 없는 항목을 삭제하고 싶다, 머릿속이 아닌 한 곳에서 해야 할 일을 관리하기 위해

**수용 기준**
- [ ] **정상 동작**: 입력란에 1자 이상 100자 이하의 할 일 내용을 입력하고 등록하면, 해당 항목이 목록에 즉시 추가되고 입력란은 빈 상태로 초기화된다.
- [ ] **정상 동작**: 목록의 각 항목에서 삭제를 실행하면 해당 항목만 목록에서 제거되고, 나머지 항목의 내용과 완료 상태는 변경되지 않는다.
- [ ] **엣지 케이스**: 목록에 항목이 0개일 때는 "등록된 할 일이 없습니다"에 해당하는 안내 문구가 목록 영역에 표시된다.
- [ ] **엣지 케이스**: 동일한 내용의 할 일을 2건 이상 등록해도 각각 별개의 항목으로 등록되며, 그중 하나를 삭제해도 나머지 항목은 유지된다.
- [ ] **엣지 케이스**: 화면을 새로고침하거나 브라우저를 닫았다가 다시 열어도, 마지막으로 등록·삭제한 결과가 그대로 표시된다.
- [ ] **에러 처리**: 내용이 비어 있거나 공백 문자로만 이루어진 경우 등록되지 않으며, "할 일 내용을 입력해 주세요"에 해당하는 오류 안내가 표시된다.
- [ ] **에러 처리**: 100자를 초과하는 내용은 등록되지 않으며, "최대 100자까지 입력할 수 있습니다"에 해당하는 오류 안내가 표시된다.

### 기능 2: 완료 체크 및 상태 변경

**사용자 스토리**
> 개인 사용자로서, 끝낸 할 일을 완료로 표시하고 필요하면 다시 미완료로 되돌리고 싶다, 남은 할 일과 끝낸 할 일을 구분해서 진행 상황을 파악하기 위해

**수용 기준**
- [ ] **정상 동작**: 항목의 완료 표시를 선택하면 해당 항목의 상태가 "완료"로 바뀌고, 미완료 항목과 시각적으로 구분되는 표시(예: 취소선)가 적용된다.
- [ ] **정상 동작**: 완료 상태인 항목의 완료 표시를 다시 선택하면 "미완료" 상태로 되돌아가고, 완료 표시가 해제된다.
- [ ] **정상 동작**: 화면에 전체 항목 수와 완료 항목 수가 "완료 N / 전체 M" 형태로 표시되며, 완료 상태를 변경할 때마다 값이 갱신된다.
- [ ] **엣지 케이스**: 완료 상태를 연속으로 5회 이상 전환해도 상태 값이 어긋나지 않고, 마지막으로 선택한 상태가 목록과 카운트에 동일하게 반영된다.
- [ ] **엣지 케이스**: 완료 상태로 표시된 항목도 삭제할 수 있으며, 삭제 후 완료 항목 수와 전체 항목 수가 각각 1씩 감소한다.
- [ ] **에러 처리**: 상태 변경 결과가 저장되지 않은 경우, 항목은 변경 직전 상태로 되돌아가고 "상태를 저장하지 못했습니다"에 해당하는 오류 안내가 표시된다.

### 기능 3: 마감일 설정 및 정렬

**사용자 스토리**
> 개인 사용자로서, 할 일에 마감일을 지정하고 마감일 순서로 목록을 정렬해서 보고 싶다, 어떤 일을 먼저 처리해야 하는지 판단하기 위해

**수용 기준**
- [ ] **정상 동작**: 할 일 등록 시 또는 등록 후에 연·월·일 단위의 마감일을 지정할 수 있고, 지정한 마감일이 해당 항목에 표시된다.
- [ ] **정상 동작**: 정렬 기준을 "마감일 빠른 순"으로 선택하면 마감일이 이른 항목부터 순서대로 표시되고, "마감일 늦은 순"을 선택하면 역순으로 표시된다.
- [ ] **정상 동작**: 마감일이 오늘 날짜보다 이전인 미완료 항목은 "기한 지남"에 해당하는 표시로 다른 항목과 구분된다.
- [ ] **엣지 케이스**: 마감일을 지정하지 않은 항목은 정렬 기준과 무관하게 마감일이 있는 항목들보다 뒤에 배치되고, 등록한 순서대로 표시된다.
- [ ] **엣지 케이스**: 마감일이 동일한 항목이 2건 이상일 경우, 먼저 등록된 항목이 앞에 표시된다.
- [ ] **엣지 케이스**: 선택한 정렬 기준은 화면을 새로고침한 뒤에도 유지된다.
- [ ] **에러 처리**: 존재하지 않는 날짜(예: 2월 30일)나 형식에 맞지 않는 날짜는 저장되지 않으며, "올바른 날짜를 입력해 주세요"에 해당하는 오류 안내가 표시된다.

## 3. 비기능 요구사항

### 성능
- 할 일 등록, 삭제, 완료 상태 변경 후 목록 화면에 결과가 반영되기까지 1초 이내여야 한다.
- 항목 100건이 등록된 상태에서 정렬 기준을 변경했을 때, 정렬 결과가 표시되기까지 1초 이내여야 한다.
- 화면 최초 진입 시 저장된 할 일 목록이 표시되기까지 3초 이내여야 한다.

### 보안
- 계정, 로그인, 개인 식별 정보(이름, 이메일, 연락처)를 수집하지 않는다.
- 할 일 데이터는 사용자의 기기 내부에만 보관되며, 외부로 전송되지 않는다.
- 다른 사용자와 목록을 공유하거나 열람하는 경로를 제공하지 않는다.

### 접근성
- 마우스 없이 키보드만으로 할 일 등록, 완료 상태 변경, 삭제, 정렬 기준 변경을 모두 수행할 수 있어야 한다.
- 본문 텍스트와 배경의 명도 대비는 4.5:1 이상이어야 한다.
- 화면 너비 360px 이상 1920px 이하에서 가로 스크롤 없이 목록 전체를 확인할 수 있어야 한다.
- 완료 여부는 색상만으로 구분하지 않고, 텍스트나 형태 변화(예: 취소선)로도 함께 구분되어야 한다.

## 4. 제약사항

### 기술적 제약
- 별도의 서버나 데이터베이스 없이, 사용자 기기 내부 저장만으로 동작해야 한다.
- 다중 기기 간 데이터 동기화는 지원하지 않는다. 기기나 브라우저를 바꾸면 기존 데이터는 조회되지 않는다.
- 사용자가 브라우저 저장 데이터를 삭제하면 할 일 목록도 함께 사라지며, 복구 수단을 제공하지 않는다.
- 최신 데스크톱·모바일 웹 브라우저 최신 버전 2개 세대에서 동작하는 것을 기준으로 한다.

### 비즈니스 제약
- 학습 및 데모 목적의 프로젝트로, 수익 모델과 외부 결제 요소를 포함하지 않는다.
- MVP 범위는 위 기능 3개로 한정하며, 범위 확장은 MVP 완료 이후에 검토한다.
- 개인 식별 정보를 수집하지 않으므로 별도의 개인정보 처리 절차는 적용하지 않는다.
- 다국어 지원 없이 한국어 단일 언어로 제공한다.

## 5. 성공 지표
- 기능 요구사항 3개에 정의된 수용 기준 20개 중 20개(100%)가 검증 통과한다.
- 신규 사용자가 화면 진입 후 첫 할 일을 등록 완료하기까지 30초 이내에 도달한다.
- 할 일 10건을 등록한 뒤 화면을 새로고침했을 때, 10건 모두 내용·완료 상태·마감일이 변경 없이 유지된다.
- 등록 100건, 완료 상태 변경 100회, 삭제 100회를 연속 수행하는 동안 화면이 멈추거나 데이터가 유실되는 사례가 0건이다.
- 키보드만 사용해 등록 → 완료 체크 → 마감일 지정 → 정렬 변경 → 삭제까지 전 과정을 중단 없이 수행할 수 있다.

## 향후 확장 (MVP 이후)
- **카테고리 분류**: 할 일을 사용자가 정의한 분류(예: 업무, 개인, 학습)에 배정하고, 분류별로 필터링해 조회하는 기능
- **우선순위 분류**: 할 일에 높음/보통/낮음 등의 우선순위를 지정하고, 우선순위 기준으로 정렬하는 기능
- **할 일 내용 수정**: 이미 등록한 항목의 내용을 다시 편집하는 기능
- **검색 및 필터**: 내용 키워드로 항목을 검색하고, 완료/미완료 상태별로 걸러 보는 기능
- **완료 항목 일괄 정리**: 완료 상태 항목을 한 번에 삭제하거나 별도 영역으로 이동하는 기능
- **데이터 내보내기/가져오기**: 목록을 파일로 저장하고 다른 기기에서 불러오는 기능
