# todolist 생성하기

## 구현 절차

1. `/sdd-init`으로 todolist 프로젝트를 초기화하여 필요한 파일과 디렉토리를 생성
2. `/sdd-plan 할 일 관리 앱을 만들어줘` 요청
   1. 간단한 클로드 질문들에 답변하여 요구사항을 정의
   2. sdd-toolkit의 plannder 에이전트가 PRD 문서 산출
3. `/sdd-design` 요청
   1. sdd-toolkit의 architect 에이전트가 PRD 문서를 기반으로 TECH SPEC 문서 산출
4. `/sdd-build` 요청
   1. sdd-toolkit의 developer 에이전트가 TECH SPEC 문서를 기반으로 코드를 생성
5. `/sdd-review` 요청
   1. sdd-toolkit의 reviewer 에이전트가 PRD, TECH SPEC 문서를 기반으로 코드를 리뷰
6. 실제 코드를 실행하여 동작 확인

## 회고

확실히 문서 전문가라서 그런지 스킬이나 에이전트를 정의하는 부분이 체계적이고 명확하게 되어있다.
다만 전반적인 흐름이 AI에게 모든 것을 맡기는 구조라서 문서로 작성된 요구 사항 중 일부가 누락되는 경우가 있었다.
그래서 AI에게 다시 어떤 기능이 미흡하니 추가해달라고 하거나 기능은 있으나 UI에 반영되지 않은 부분을 찾아 개선해달라는 요청을 해야 했다.
이러한 점은 이 분이 다루는 SDD에 대해 아쉬움이 남는 부분이었다.
