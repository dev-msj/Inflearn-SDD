# 인프런 SDD 강좌

SDD 강좌를 수강하며 작성한 코드와 자료를 정리하는 저장소.
강사는 13년 간 수백 수천 건의 정부 지원 사업 기획서를 작성한 문서 전문가다.
비개발자 출신으로 사무 자동화를 위해 부트 캠프를 통해 AI 기반 개발자로 활동 중이다.

## sdd-toolkit 등록하기

1. 로컬 디렉토리

   ```cmd
   /plugin marketplace add ./sdd-toolkit
   /plugin install sdd-toolkit@sdd-local
   ```

2. github 마켓

   ```cmd
   /plugin marketplace add {user}/{repo}
   /plugin install sdd-toolkit@sdd-local
   ```

3. 공식 등록

   ```cmd
   claude.ai/settings/plugins/submit
   ```
