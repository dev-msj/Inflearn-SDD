# /trade-plan - 매매 계획 수립

## 동작
@trade-planner 에이전트를 호출하여 `output/` 의 분석 보고서를 실행 가능한 조건부
매매 계획으로 변환합니다. **매수/매도를 권유하지 않으며**, 사용자가 진입을 결정했을 때
규율 있게 실행하기 위한 가격 조건과 포지션 크기를 설계합니다.

## 사용법
```
/trade-plan                    # output/ 의 보고서 목록에서 선택
/trade-plan NAVER              # 종목명으로 보고서 지정
```

## 전제조건
- **분석 보고서 필수**: `output/*_분석보고서.md`
  - 없으면 → stock-market-analysis 스킬로 분석을 먼저 수행하도록 안내 후 중단
- **리스크 파라미터 필수**: 없으면 사용자에게 질문 (추측 금지)
  1. 총 투자 자본
  2. 1회 거래 허용 손실률 (통상 1~2%)
  3. 투자 기간 (단기/중기/장기)

## 실행 순서

### Step 1: 전제조건 체크
```
output/*_분석보고서.md 존재 확인
├── 없음         → 분석 선행 안내 후 중단
├── 1개          → 해당 보고서 사용
└── 여러 개      → 사용자에게 대상 확인

리스크 파라미터 3종 확인
└── 하나라도 없음 → 사용자에게 질문 후 대기
```

### Step 2: 에이전트 활성화
- @trade-planner 에이전트 호출
- stock-market-analysis 스킬의 `position_calc.py` 사용

### Step 3: 보고서에서 근거 추출
- 3.4 기술적 위치 → SMA 지지선, 연환산 변동성, MDD
- 7. 종합 결론 → **반증 조건** (청산 트리거의 원천)
- 6. 리스크 요인 → 시나리오 분기
- 컨센서스 목표가 → 손익비 상단

### Step 4: 포지션 계산 (스크립트 필수)
```bash
python .claude/skills/stock-market-analysis/scripts/position_calc.py \
  --capital <총자본> --risk-pct <허용손실률> \
  --entry <진입가> --stop <손절가> --target <목표가> \
  --volatility <연환산변동성> \
  --fit-max-position --r-ladder 1,2,3 --scale-in 3
```
암산 금지. 스크립트의 경고(집중도 초과, 손익비 미달, 손절폭 부족)는 그대로 전달.
수량 조정은 `--fit-max-position` / `--shares` 로 하고, risk-pct 역산 편법 금지.

### Step 5: 계획 문서화
`output/<종목명>_<YYYYMMDD>_매매계획.md` 저장 후 필요 시 PDF 변환:
```bash
python .claude/skills/stock-market-analysis/scripts/export_report.py \
  "output/<종목명>_<YYYYMMDD>_매매계획.md"
```

## 출력물
- `output/<종목명>_<YYYYMMDD>_매매계획.md`
- 선택: 동명의 `.pdf`

## 자체 점검 기준

| 항목 | 기준 |
|---|---|
| 손익비 | 2:1 이상 |
| 포지션 집중도 | 단일 종목 20% 이하 |
| 손절폭 | 일간 변동성 2σ 이상 |
| 청산 조건 | 가격 조건 + 시간 조건 모두 존재 |
| 근거 추적 | 모든 숫자가 보고서 또는 스크립트 출처 |

## 주의사항
- ❌ 매수/매도 권유 금지 — 조건부 규칙만
- ❌ 가격 예측 금지
- ❌ 목표주가 임의 산출 금지 (컨센서스·기술적 저항 인용만)
- ❌ 리스크 파라미터 임의 가정 금지
- ✅ 손절가를 진입가보다 먼저 확정
- ✅ 면책 고지 포함
